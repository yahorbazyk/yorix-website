# Arabic localization pilot

Imported verbatim from the November localization handoff (pilot, phase \`pilot\`) and wave 2 (phase \`wave2\`). Generated content and JSON-LD carry the actual publication date, November 25, 2026.

Rebuild a batch with `python3 -B scripts/prepare-localized-batch.py --lang ar --phase <phase> --date YYYY-MM-DD`,
then `python3 -B scripts/prepare-english-articles.py --date YYYY-MM-DD` for the sitemap.
Check rendered pages with `python3 -B scripts/check-localized-batches.py --sitemap-urls <n>` against a production server.
